# Veil Arena v0.2.1（公開前の案）

Veilの変更を繰り返し検証するため、netns一括試験の失敗診断と試験用ランチャーの安定性を改善するソース版の候補です。タグ・リリースは未作成です。

## v0.2.0からの変更

- 完了したworkflowの証拠を読み、最初の不一致、実際／期待の終了コード、記録された時間、詳細と該当ログを示す `scripts/diagnose_netns.py` を追加しました。
- 新しく準備する `arena-netns`／`arena-netns-volume` では、失敗時にランチャー終了・証拠回収後の診断を自動表示します。診断できない場合も理由を表示し、元の終了コードを維持します。診断自体には5秒の上限があります。
- 意図したwatchdog停止、watchdog証拠の検証失敗、VM間の受け入れ条件違反、停止・回収・証拠同期の異常を区別します。通常VMの停止異常を、部分的な子報告の失敗で上書きしません。
- workflow単体試験のダミーランチャーを固定実行可能fixtureに変更しました。並行した実行対象への書き込みと子生成が重なるETXTBSYを再現・追跡し、起動時の競合を避けています。本番の期限・期待値・VM回収処理は緩めていません。

古いimmutableな正式入口には診断は追加されません。既存guestからホスト側の入口を準備し直してください。[SSD運用手順](../MAC_SSD_VM.md)と[診断手順](../NETNS_WORKFLOW.md#失敗した段階と証拠を調べる)を参照してください。

## 確認範囲と公開前の条件

Text file busy修正はMac／Linuxの回帰試験、Linuxの単独500回・4件並行500回、MacのNixパッケージビルドで確認しました。反復成功は全環境での無発生保証ではありません。元の保存済み失敗にはsyscall追跡がなく、その1件のFD保持元まで証明したものではありません。

PR #15マージ後main `dbe0edc76f9005cd6b4c995f8ceb019626ed4df8` の[Linux x86_64 CI](https://github.com/mt4110/veil-arena/actions/runs/39140468729)は成功しました。VM実行と公開前の残項目は[準備記録](../V0_2_1_READINESS.md)で区別します。

公開準備PRではRust・controller・両lockfile・Nixのパッケージ版を0.2.1へ揃えました。版上げ後のMacチェックとSSD正式入口の結果は準備記録にまとめ、対象headのGitHub CIはPRで照合します。公開時は取り込み後mainの対象コミットとCIを再確認します。

0.2.1へ版を揃えた後、Macの固定環境でチェック一式とcontrollerのNixパッケージ内蔵試験が成功しました。既存guestを再利用したSSD正式入口のdailyも、新規VM 1回・16ケースで期待結果と一致し、証拠の停止前同期・所有QEMUの正常回収を確認しました。[版上げ後の集計](../validation/v0.2.1-preparation-20261019.json)に実行入力のhashと確認範囲を記録しています。追加2 VMのacceptanceや新規ビルドguestの検証とは分けています。

## 配布と既知の制約

- ソースのみを配布する方針です。VMイメージ・依存バイナリ・生ログ／PCAPは同梱しません。Rust・スクリプト・文書はMIT、参照eBPFのCコードはGPL-2.0-onlyです。
- Linux x86_64／KVMの過去の期限超過は、同じ旧イメージでの1回の再実行では未再現でした。根本原因と継続して成功する条件は未確定で、現在のソースによる追加fresh VMを含む受け入れは未完了です。今回の診断改善で解消したとは扱いません。
- SSD試験はMac ARM64／native QEMU・TCGと、既存の検証済みguest bundleの組合せです。guest内のArenaパッケージは0.1.0で、今回のソースから新たにビルドしたguestの検証ではありません。
- 診断は記録された証拠の説明であり、試験の再判定や根本原因の自動確定ではありません。診断コマンドの終了0も元の試験合格を意味しません。異常系の診断回帰はダミー子プロセス・証拠での確認と、実VMの確認を分けます。
- IPv6のwire試験、TCPの限定drop、固定fixture以外の異常入力、任意時点の中断、kernel panic・電源断、Mac／HVF、Linux ARM64／KVM、SSDの稼働中抜去・同時書換えは未確認です。
- 第三者試用とk8sは保留です。性能・工数削減・製品価値は未測定で、未知の攻撃への防御やホストの無条件な安全性は保証しません。
