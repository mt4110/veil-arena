## 判定

固定入力について、指定した失敗を検出し、正常試験を繰り返し、結果を保存する技術的条件を満たした。準備と集計を1つの入口へまとめる方針を継続する。機能拡張と追加の速度研究はここで止め、普段のBlackhole開発で使う。

人的工数・理解負担の削減は未確認。実利用者の操作時間と手動診断の記録は、自動実行で代用できない。これを製品価値の証明としてM3全体や主力プロダクトへの格上げを完了扱いにしない。

## 差分レビューで修正した点

以前の集計側は19段階と重複のない名前を要求していたが、実際の段階名・順序との一致は要求していなかった。また、ソースの識別情報とバイナリhashは型だけで確認し、空の識別情報を十分に拒否していなかった。

未知／並べ替えた段階名と、欠けたソース・バイナリ識別情報を拒否する2つの回帰試験を追加したところ、修正前は2試験が失敗した。次の条件を補強した。

- Rust runnerの19段階の名前と順序が、既知の契約と一致する。
- ソースのファイル一覧が空でなく、集合hashとバイナリhashが64桁の小文字hexである。
- 中断・期限超過・環境エラーの途中結果は、正常試験の完全な証拠へ読み替えない。

現行コードでMacの全Python 36試験、Linuxの追加12試験が成功した。Linuxでも指定した修正前の失敗→正常19段階→正常19段階を確認した。Macの比較試験も全4回が同じ結果を満たす。成功側のソース／バイナリ識別情報は4回を通じて同一で、各runの開始・終了も不変だった。

これらは保存報告の構造検査であり、悪意あるコードが作った報告の真正性を保証する仕組みではない。信頼するローカルプロジェクトに対する既存Rust runnerの出力を扱う。

Blackholeの変更も確認し、最終パス要素のsymlink拒否・FIFOのwriter待ち回避・FDの種類確認という限定した修正であることを維持した。親ディレクトリやdeviceのopen副作用まで防ぐ説明に広げない。依存版とCargo.lockの変更はない。READMEの説明を段落に分けたが、製品機能は増やしていない。

## PR #3のPython失敗証拠に関するレビュー対応

2026-10-11、PR #3のレビューで、`python-tests`の失敗証拠をstdoutから読む問題が指摘された。unittestが通常stderrへ出す失敗名を認識できず、before確認が失敗して正常試験へ進めなかった。Python試験はstderr、他の対応段階は従来のstdoutを照合するよう修正した。ログのファイル名・通常ファイル・2 MiB上限の検証は維持した。

stderrの証拠を受理、stdoutだけの文字列を拒否、不正なstderrパスを環境エラーとする回帰試験を追加し、修正前は3ケースが失敗、修正後は全Python 37試験が成功した。Mac ARM64の固定Nix環境で整形・Clippy・Rust試験・3 systemのNix定義評価も成功した。

隔離したBlackholeコピーへ意図的に失敗するunittestを追加し、実際の失敗名がstderrだけに出ることを確認した。一括入口はその失敗を検出した後、元のBlackholeチェックアウトで正常19段階を2回完了した。これは集計経路の試験用fixtureであり、新しいBlackhole不具合の発見ではない。依存・ビルドcacheを再利用し、新規VMは起動していない。証拠はGitignoredの`artifacts/pr3-python-stderr-20261011/`（`before.log`、`checks.log`、`batch.log`、各summary／Rust報告／ログ）へ保存した。

## 比較方法

Mac ARM64の固定Nix shell内で、同じwarm cache・同じ入力・同じRust runnerを使った。個別手順を再構成し、次の4呼び出しを順に実行した。

1. Arenaのoffline build
2. 修正前のsnapshotでRust runnerを実行し、指定回帰試験の失敗を確認
3. 修正後のチェックアウトで正常試験
4. 同じチェックアウトで正常試験を再実行

一括入口はPython CLIを1回呼び出し、内部で同じ4呼び出しを行った。順番は個別→一括→一括→個別。測定用スクリプトが両方式を実行しており、人が4コマンドを入力した時間ではない。判定には同じ集計関数を使用しているため、判定器の独立検証でもない。元の回帰失敗の再現と拒否条件の試験は別の証拠として保存した。

Nix shellへの初期入場時間、対話的な結果確認、入力・判断・説明に必要な時間は含まない。両方式とも既に準備済みの依存を使用した。追加の設定変更・依存取得・黙った再試行は行わなかった。
